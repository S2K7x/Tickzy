# Tickzy Research Repository — Central Index

Tickzy is a planned B2B customer support & ticketing platform. **This repository currently contains research only — no application code (by design).** Research checkpoint: 2026-11-19.

**Start here:** [progress/research-status.md](progress/research-status.md) (top findings & checkpoint) → [tickzy/product-vision.md](tickzy/product-vision.md) → [comparisons/master-feature-matrix.md](comparisons/master-feature-matrix.md).

## Evidence labels
- **VERIFIED** — confirmed from a primary source (vendor docs/pricing/official changelog) fetched on the research date.
- **PARTIALLY VERIFIED** — secondary sources, or primary source with gaps / product knowledge not re-fetched.
- **UNVERIFIED** — single weak source, vendor claim without corroboration, or hypothesis.
- **OUTDATED** — superseded by newer primary information.
