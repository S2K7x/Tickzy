# Help Scout — Investigation

- **Research date:** 2026-11-19 · **Mission:** M10
- **Primary sources:** [Help Scout pricing](https://www.helpscout.com/pricing/) (fetched 2026-11-19). (helpscout.com/llms.txt returned 404.)
- **Confidence:** HIGH pricing; MEDIUM features.

## 1. Position
Simple, human-feeling shared inbox + Docs (KB) + Beacon (embeddable widget) for SMBs and "customer-first" companies. Known for UX simplicity and pricing transparency; **contact-based → user-based pricing** history.

## 2. Pricing — VERIFIED
| Plan | $/user/mo (annual) | Inboxes / Docs sites |
|---|---|---|
| Free | $0 | 5 users, 1 Inbox, 1 Docs site |
| Standard | 25 | 2 inboxes (+$10/mo each), 2 Docs sites (+$20) |
| Plus (popular) | 45 | 5 inboxes; **group conversations by company**; internal teams |
| Pro | 75 | 10 inboxes |
| **Envoy (AI agent "Scout")** | **$0.75 per resolution** | "A single conversation resolved by Scout without human assistance"; 3-month trial |
Product modules in nav: **Inbox, Envoy, Copilot, Signal, Updates** (Signal ≈ customer feedback/insights; Updates ≈ announcements — PARTIALLY VERIFIED by nav labels only).

## 3. Notable patterns — PARTIALLY VERIFIED
Beacon widget (chat + docs search + contact form in one), saved replies, workflows (automatic/manual), collision detection ("traffic cop"), customer properties panel, ratings, Docs with AI Answers, ContactStatus (no-login status pages?). Strong emphasis on email that "looks like a normal email" (no ticket numbers in subject).

## 4. Takeaways
1. **Lowest published per-resolution AI price ($0.75)** in this set — the market price for AI resolutions is converging on **$0.75–$1.50**.
2. "Group conversations by company" is a paid feature here — B2B account grouping is a known upsell lever even in SMB tools.
3. Help Scout's free tier (5 users) is a powerful PLG acquisition channel Tickzy should replicate.
