# Gorgias — Investigation

- **Research date:** 2026-11-19 · **Mission:** M11
- **Primary sources:** [gorgias.com/llms.txt](https://www.gorgias.com/llms.txt), [pricing](https://www.gorgias.com/pricing).
- **Confidence:** HIGH pricing.

## 1. Position — VERIFIED
"Conversational AI platform for ecommerce" — Shopify-first helpdesk (also WooCommerce, BigCommerce, Magento), positions support as a **revenue centre** (AI Shopping Assistant, revenue attribution). Not a B2B SaaS competitor; included for **pricing-model and vertical-context lessons**.

## 2. Pricing — VERIFIED
| | Starter | Basic | Pro (popular) | Advanced |
|---|---|---|---|---|
| Base (helpdesk) | ~$10/mo | ~$60/mo | ~$360/mo | ~$900/mo |
| Tickets included | 50/mo | 300/mo | 2,000/mo | 5,000/mo |
| User seats | 3 | 500 | 500 | 500 |
| Overage | $0.40/ticket | $40/100 | $36/100 | $36/100 |
| AI Agent per automated interaction | $1.00 | $0.90 | $0.90 | $0.85 |
| **API rate limit** | **2 req/s** | 2 req/s | 2 req/s | 2 req/s |
"Helpdesk scales from 50 to 5,000 tickets a month, **never priced per agent**." (Base price pairings inferred from listed amounts — PARTIALLY VERIFIED.)

## 3. Lessons
1. **Ticket-volume pricing with ~unlimited seats** is proven at scale in e-commerce. For B2B, volume is low and value per ticket is high, so seats/accounts are better value metrics — but the "unlimited collaborators" idea transfers.
2. Deep commerce context (order data, actions like cancel/refund/discount) in the sidebar & AI actions = the e-commerce equivalent of B2B's CRM/billing/product-usage context. Tickzy's equivalent: **actions on your own product via API/MCP** (reset API key, extend trial, check job status).
3. 2 req/s API limit illustrates how low incumbents set limits; a dev-friendly Tickzy should differentiate.
