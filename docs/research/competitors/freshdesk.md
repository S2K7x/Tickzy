# Freshdesk (Freshworks) — Investigation

- **Research date:** 2026-11-19 · **Mission:** M09
- **Primary sources:** [Freshdesk pricing](https://www.freshworks.com/freshdesk/pricing/), [freshworks.com/llms.txt](https://www.freshworks.com/llms.txt).
- **Confidence:** HIGH pricing; MEDIUM features (product knowledge, not re-verified page by page).

## 1. Position
Mid-market, price-competitive Zendesk alternative within the Freshworks suite (Freshdesk, Freshservice ITSM, Freshsales CRM, Freshchat). Strong in SMB/mid-market, India, EMEA. AI brand: **Freddy AI** (Agent, Copilot, Insights).

## 2. Pricing — VERIFIED (annual)
| Plan | $/agent/mo |
|---|---|
| Growth | 19 (AI-powered email service) |
| Pro | 55 |
| Enterprise | 89 |
| Freddy AI Copilot | +$29/agent/mo |
| Freddy AI Agent | sessions bundles; additional **$49 per 100 sessions** |
| **MCP actions** | **$15 per 1,000 actions** (Freshworks now meters MCP tool calls) |
| Connector app tasks | $80 per 5,000 tasks |
| **Day passes** | $2–$12 per pass (occasional agents) |
(Free plan historically available for small teams — not re-verified.)

## 3. Notable capabilities — PARTIALLY VERIFIED
Ticketing with statuses/priorities/types, parent-child tickets, linked tickets (tracker), shared ownership, collision detection, canned responses, scenario automations (one-click multi-action macros), time-triggered/event-triggered/ticket-creation automations, skill-based & omniroute, SLA policies with escalations, multilingual KB, customer portal, Field Service Management, Freddy AI Agent (chat/email deflection), Freddy Copilot, Freddy Insights, sandbox (Enterprise), audit logs, custom objects, marketplace apps (FDK — Freshworks Developer Kit, serverless app framework).

## 4. Takeaways
1. **Day passes** are the cleanest solution to the B2B "occasional responder" problem (engineers/CSMs who answer a few tickets a month). Tickzy should offer *light/collaborator seats* or day passes.
2. Metering MCP actions shows vendors expect agent-driven API usage to grow — Tickzy should price MCP/API use generously but design metering infrastructure anyway.
3. Scenario automations (manual multi-action macros) ≈ Pylon macros/Plain "Run workflow" — standard.
